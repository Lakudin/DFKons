АКТУАЛЬНОСТЬ И ПРОБЛЕМА

Сегодня большинство людей ведут учёт личных финансов в разрозненных форматах:
заметки, таблицы, банковские приложения. При этом не всегда есть наглядная
картина: сколько денег остаётся, как меняется баланс со временем и на что
уходит больше всего средств. Особенно это важно, когда пользователь хочет
самостоятельно планировать бюджет, а не только смотреть историю операций в банке.

Целью моей работы стала разработка мобильного Android-приложения, которое
позволяет вести учёт доходов и расходов, анализировать статистику и принимать
решения на основе визуализированных данных. Практический результат — приложение
DFKons, предназначенное для повседневного финансового планирования.


ЦЕЛЬ, ЗАДАЧИ И ОБЪЕКТ ИССЛЕДОВАНИЯ

Цель работы — создать мобильное приложение для учёта финансовых операций,
анализа статистики и контроля динамики баланса.

Для достижения цели были поставлены и решены следующие задачи:
  1. Проанализировать предметную область и существующие подходы к учёту финансов.
  2. Спроектировать архитектуру приложения и структуру базы данных.
  3. Реализовать регистрацию, авторизацию и выход из аккаунта.
  4. Реализовать добавление, хранение и удаление финансовых операций.
  5. Реализовать модуль статистики с графиками и фильтрацией по периоду.
  6. Реализовать модуль курсов валют и протестировать приложение.

Объектом исследования являются процессы учёта личных финансов и анализа
статистических показателей. Предметом — методы и средства разработки мобильных
приложений на платформе Android.


ЧТО БЫЛО РАЗРАБОТАНО

В результате работы создано клиентское Android-приложение DFKons со следующими
функциональными возможностями:

  • Регистрация и вход пользователя с локальным хранением учётной записи.
  • Добавление финансовых операций двух типов: доход и расход.
  • Выбор категории, суммы, даты и описания операции.
  • Просмотр сводной статистики: общий доход, общий расход, текущий баланс.
  • Фильтрация данных по выбранному периоду (дата начала и дата окончания).
  • График динамики баланса — одна линия, отражающая влияние доходов и расходов.
  • Круговая диаграмма расходов по категориям и список топ-категорий.
  • Модуль курсов валют с загрузкой актуальных данных с сайта Центрального банка РФ.

Приложение ориентировано на Android 7.0 и выше (minSdk 24), что обеспечивает
широкую совместимость с современными и относительно старыми устройствами.


ТЕХНОЛОГИИ И АРХИТЕКТУРА

При разработке использован язык программирования Kotlin и современный
инструментарий Android:

  • Jetpack Compose — для построения пользовательского интерфейса;
  • Material Design 3 — для единообразного и понятного оформления;
  • MVVM и Clean Architecture — для разделения ответственности между слоями;
  • Room — для работы с локальной базой данных SQLite;
  • Retrofit и Gson — для получения курсов валют по HTTP;
  • Navigation Compose — для навигации между экранами.

Архитектура приложения разделена на три основных слоя:

  1. Presentation — экраны, ViewModel, компоненты интерфейса (графики, формы).
  2. Domain — бизнес-модели и сценарии использования (Use Cases).
  3. Data — репозитории, DAO, сущности базы данных, сетевой API.

Такой подход упрощает сопровождение кода: логика хранения данных отделена от
логики отображения, а бизнес-правила сосредоточены в слое domain.


БАЗА ДАННЫХ

Для хранения информации используется локальная реляционная база данных SQLite,
доступ к которой организован через ORM-библиотеку Room. Файл базы данных
называется finance_database и хранится на устройстве пользователя.

В базе данных предусмотрены две основные таблицы:

  • users — учётные записи пользователей (логин и хэш пароля);
  • transactions — финансовые операции (сумма, категория, тип, дата, описание,
    привязка к пользователю).

Каждая операция привязана к конкретному пользователю через поле userId, что
позволяет изолировать данные разных аккаунтов. Пароли не хранятся в открытом
виде — применяется хэширование.


ОСНОВНЫЕ ЭКРАНЫ И МОДУЛИ

Приложение включает следующие ключевые экраны:

  1. Экран входа и регистрации — пользователь создаёт аккаунт или входит в
     существующий. После успешной авторизации открывается главный экран.

  2. Главный экран — содержит нижнюю навигацию с тремя разделами:
     «Операция», «Статистика», «Курсы валют». Также реализован выход из аккаунта.

  3. Экран добавления операции — пользователь выбирает тип (доход или расход),
     категорию, вводит сумму, дату и при необходимости описание. Категории
     разделены: для доходов (зарплата, фриланс, перевод и др.) и для расходов
     (продукты, транспорт, коммунальные услуги и др.).

  4. Экран статистики — отображает сводные показатели, фильтр по периоду,
     график динамики баланса, круговую диаграмму расходов по категориям,
     список топ-категорий и последние операции с возможностью удаления.

  5. Экран курсов валют — показывает актуальные курсы, полученные с API
     Центрального банка Российской Федерации (cbr-xml-daily.ru).


РЕАЛИЗАЦИЯ ГРАФИКА И АНАЛИТИКИ

Одной из центральных задач проекта была визуализация финансового состояния
пользователя. На графике отображается накопительный баланс: доходы увеличивают
значение, расходы — уменьшают. Данные группируются по календарным дням, после
чего строится плавная кривая с заливкой области под графиком.

Ось Y графика начинается с нуля, что позволяет наглядно оценить масштаб
накопленного баланса, а сама линия отражает фактическую сумму на каждый день
периода. Дополнительно реализована фильтрация по датам, чтобы пользователь
мог анализировать как весь период, так и выбранный интервал.

Для анализа структуры расходов используется круговая диаграмма (PieChart),
которая показывает, какая доля бюджета приходится на каждую категорию.


ТЕСТИРОВАНИЕ И РЕЗУЛЬТАТЫ

В процессе разработки и отладки были проверены основные сценарии использования:

  • регистрация и вход пользователя;
  • добавление операций дохода и расхода;
  • корректность расчёта баланса и сводной статистики;
  • работа фильтра по периоду;
  • отображение графика и диаграммы при наличии данных;
  • загрузка курсов валют при наличии подключения к интернету;
  • удаление операций и обновление статистики после изменений.

Приложение успешно собирается в установочный APK-файл и может быть установлено
на Android-устройство для демонстрации.


ПРАКТИЧЕСКАЯ ЗНАЧИМОСТЬ И ВЫВОДЫ

Практическая значимость работы заключается в том, что создано готовое мобильное

финансов без привязки к конкретному банку. Все данные хранятся локально на
устройстве, что обеспечивает автономную работу основных функций.

В ходе выполнения дипломной работы:

  • создана база данных для хранения пользователей и операций;
  • реализованы модули авторизации, учёта операций, статистики и курсов валют;
  • разработаны собственные компоненты визуализации данных на Jetpack Compose.

Поставленная цель достигнута, все задачи выполнены. Разработанное приложение
DFKons решает задачу анализа статистических данных и поддержки финансового
планирования пользователя.

В: На какой базе данных работает приложение?
О: Локальная SQLite через библиотеку Room. Серверной БД нет.

В: Где хранятся пароли?
О: В таблице users в виде хэша, не в открытом виде.

В: Откуда берутся курсы валют?
О: Из публичного API ЦБ РФ (cbr-xml-daily.ru) через Retrofit.

В: Как считается баланс на графике?
О: По дням суммируются доходы и вычитаются расходы, формируется накопительный
   баланс за выбранный период.

В: Почему Clean Architecture?
О: Чтобы отделить UI, бизнес-логику и данные — проще тестировать и развивать.

В: Какие требования к Android?
О: Android 7.0 и выше (API 24+).
